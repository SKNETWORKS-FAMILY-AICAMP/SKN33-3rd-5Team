## 답변 평가 CLI

`eval/answer_cases.example.jsonl`의 smoke 4건으로 `run → prepare → score`를 실제 실행했다.
이 실행도 BM25/template이며 실제 Qwen 평가가 아니다.

- 기대 상태 일치 4/4, 보류 판정 2/2, 필수 단일 행 명령어 원문 검사 1/1.
- 의미 검수는 0/1로 남겨 Faithfulness, Answer Relevancy, Citation Precision,
  검수 기반 한국어 품질을 `null`로 출력하는지 확인했다.
- `--require-complete`는 보고서를 저장하고 exit 2를 반환했다. 미검수 답변을 통과로 간주하지 않는다.
- 완료 검수·중복/오래된 검수 거부·명령어 변형 감지 등은 별도 단위 테스트로 검증했다.

질문/출력/근거 원문을 포함하는 상세 기록은 Git 제외 경로 `artifacts/local-validation/`에 보관한다.
주요 파일은 `pr-before.json`, `pr-after.json`, `flow-results.json`,
`pr-review-tests.xml`, `pr-baseline-tests-retry.xml`, `pr-evaluation-verified/report.json`이다.
평가 재실행 절차와 입력 계약은 [답변 평가 가이드](../llm-answer-evaluation.md)를 따른다.
